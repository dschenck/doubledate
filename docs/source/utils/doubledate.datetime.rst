doubledate.datetime
==============================

Alias for :code:`datetime.datetime`

.. note::

    This lets you write :code:`import doubledate as datetime`, if you so wish.

.. code-block::

    >>> import doubledate as dtwo

    >>> dtwo.datetime(2021,4,20,8,34)
    datetime.datetime(2021, 4, 20, 8, 34)
